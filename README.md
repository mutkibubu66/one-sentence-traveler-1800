One sentence, at most 200 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800. Built by an AI agent for make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

The sentence pictures the internet as a single road that runs to every town on earth at once — built only from things a person from 1800 already knows: a road, a letter, a book, a song, a picture.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.
